## 🔧 Настройка

### 1. Настройка Google Forms (для сбора заявок)

1. Создайте форму в [Google Forms](https://forms.google.com)
2. Добавьте поля:
   - Тип формы
   - Имя
   - Телефон
   - Способ связи
   - Согласие на обработку
   - URL страницы
   - User Agent

3. В коде `index.html` найдите и замените:
```javascript
const FORM_ACTION_URL = 'ВАША_ССЫЛКА_НА_ФОРМУ';
const FIELD_IDS = {
    formType: 'entry.XXXXXX',  // ID полей из вашей формы - чтобы их получить нужно открыть консоль f12, отправить форму и в консоли, в network, в playloud в первом файле наверху (formResponse) - вы увидите эти id
    name: 'entry.XXXXXX',
    phone: 'entry.XXXXXX',
    // ... остальные поля
};
```

## 📱 Функционал

- **Основная форма** - в секции "Проверьте нас в деле"

## 🚀 Деплой на GitHub Pages

1. Создайте репозиторий на GitHub
2. Загрузите все файлы
3. Перейдите в **Settings → Pages**
4. Выберите ветку `main` и папку `/ (root)`
5. Сохраните - сайт будет доступен через 1-2 минуты

## 🔍 Просмотр заявок

В консоли браузера (F12) доступны команды:

```javascript
// Просмотр всех сохраненных заявок
viewBackups()

// Просмотр в виде таблицы
console.table(JSON.parse(localStorage.getItem('form_backups')))
```

Заявки автоматически попадают в Google Таблицу, связанную с формой.

2. Перейдите во вкладку **"Ответы"**
3. Нажмите на иконку Google Таблиц
