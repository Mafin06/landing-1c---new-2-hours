## 🗄️ Система сбора заявок

### Как это работает

Лендинг собирает заявки из **3 форм** и сохраняет их в Google Таблицу через Google Apps Script.

| Форма | Местоположение | Данные |
|-------|----------------|--------|
| `trial_form` | Секция «Проверьте нас в деле» | Имя, телефон, способ связи, согласие |
| `callback_form` | Модальное окно «Заказать звонок» | Телефон, согласие |
| `consultation_form` | Модальное окно «Консультация» | Имя, телефон, способ связи, согласие |

### Технологии

- **Google Sheets** — хранение данных (бесплатно, до 10 млн ячеек)
- **Google Apps Script** — обработка POST-запросов
- **JavaScript (Fetch API)** — отправка данных из браузера
- **Без бэкенда** — всё работает на статическом хостинге GitHub Pages

  }
  rateLimitCache[key] = now;
  return true;
}

// Основной обработчик POST-запросов
function doPost(e) {
  try {
    // Парсим входящие данные
    const data = JSON.parse(e.postData.contents);

    const row = [

      data.formType || 'unknown',         // form_type
      data.name || '',                    // name
      data.phone || '',                   // phone
      data.contactMethod || '',           // contact_method
      data.privacy ? 'да' : 'нет',        // privacy
      data.pageUrl || '',                 // page_url
      data.userAgent || ''                // user_agent

    // Отправляем уведомление в Telegram (опционально)

    return ContentService
      .createTextOutput(JSON.stringify({ success: true, message: 'Данные сохранены' }))
      .setMimeType(ContentService.MimeType.JSON);
      
  } catch(error) {
    return ContentService
      .createTextOutput(JSON.stringify({ success: false, error: error.toString() }))

### Шаг 4. Разверните веб-приложение

1. Нажмите кнопку **«Развернуть»** → **«Новое развертывание»**
2. В поле **«Тип»** выберите: **«Веб-приложение»**
3. Настройки:
   - **Execute as**: `Me` (ваш аккаунт)
   - **Who has access**: `Anyone` (для приёма запросов с лендинга)
4. Нажмите **«Развернуть»**
5. **Подтвердите доступ** (нажмите «Разрешить»)
6. **Скопируйте URL веб-приложения** (будет выглядеть так: `https://script.google.com/macros/s/ВАШ_ID/exec`)

### Шаг 5. Настройте лендинг

В файле `index.html` найдите и замените:

```javascript
const SCRIPT_URL = 'https://script.google.com/macros/s/ВАШ_ID/exec';
```

**Важно:** URL должен быть именно тот, который вы скопировали после развертывания.

## 🛡️ Защита форм

В лендинг встроены следующие механизмы безопасности:

| Угроза | Защита |
|--------|--------|
| **XSS (межсайтовый скриптинг)** | Экранирование всех пользовательских данных |
| **SQL-инъекции** | Неактуально (нет SQL-запросов) |
| **CSRF (подделка запросов)** | CSRF-токены в sessionStorage |
| **Спам-боты** | Honeypot (скрытое поле) + валидация полей |
| **DDoS / перебор** | Rate limiting (30 секунд между заявками) |
| **Подделка данных** | Валидация телефона и имени на клиенте |

### Rate limiting на стороне клиента:
- Не более 1 заявки в 30 секунд с одного номера телефона
- Не более 1 клика в 2 секунды на кнопки отправки

### Rate limiting на стороне Google Script:
- Ограничение запросов с одного номера/IP
- Автоматическая блокировка при превышении лимита

## ⚠️ Важные замечания

1. **Не публикуйте SCRIPT_URL в открытом доступе** — храните его в коде лендинга
2. Google Apps Script имеет лимиты для бесплатного аккаунта:
   - **20 запросов в секунду** (достаточно для небольшого бизнеса)
   - **6 минут выполнения скрипта на один вызов**
   - **30 минут общего времени выполнения в день** (для бесплатного аккаунта Google)
3. При большом трафике (>500 заявок в день) рекомендуется:
   - Перейти на платный аккаунт Google Workspace
   - Или настроить другой бэкенд (например, Formspree, Airtable)
